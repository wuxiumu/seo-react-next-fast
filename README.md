## 是什么 / 不是什么

| 是 | 不是 |
|---|---|
| Next.js SEO 性能模板方案与定制入口 | 已上线可商用的完整建站 SaaS |
| title/description/OG/JSON-LD/sitemap 约定 | 「保证首页必上百度首页」的玄学承诺 |
| 可白标的营销站 / 文档站起点 | 灰色刷量、黑帽 SEO 工具 |

## MVP 路线图

1. **M1**：App Router 骨架 + SEO 字段组件 + 样例页  
2. **M2**：sitemap / robots / OG 图约定 + Lighthouse 基线  
3. **M3**：内容 MDX + i18n（zh/en）  
4. **M4**：白标主题与一键部署说明  

详见 `docs/ROADMAP.md` / `docs/CHECKLIST-M0.md`。

## SEO 字段预留（产品页 HTML 统一生成时用）

| 字段 | 用途 |
|---|---|
| `seo_title` | `<title>` / OG title |
| `seo_description` | meta description |
| `canonical_url` | 规范 URL |
| `og_image` | 分享图 |
| `robots` | 如 `index,follow` |
| `json_ld_type` | SoftwareApplication / WebPage / FAQPage |
| `hreflang` | zh-CN / en |
| `site_name` | 白标品牌名 |
